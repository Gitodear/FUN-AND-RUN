HOW TO USE:
───────────

1. Double-click "index.html" to open in your default browser
   OR
   Right-click index.html → Open with → [Your Browser]

2. Click through the screens to experience the interactive proposal

3. Make your choice between YES and NO buttons


FOLDER CONTENTS:
────────────────

✓ index.html       - Main web page (open this file!)
✓ styles.css       - All styling and animations
✓ script.js        - All interactive features and logic

FEATURES:
─────────

✨ 5 interactive screens with smooth transitions

TROUBLESHOOTING:
────────────────

Problem: Page won't open
Solution: Try a different browser (Chrome recommended)

Problem: Buttons don't work
Solution: Check if JavaScript is enabled in browser settings

Problem: Looks ugly on mobile
Solution: That shouldn't happen - zoom in/out to adjust
